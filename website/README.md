# LiquidGlassX Website

This is the browser preview and release-information site for LiquidGlassX. Product status, package version, architecture, checksum, and download state are sourced from `src/data/releases.json`.

The application uses React, TypeScript, Vite, locally bundled Tabler icons, locally bundled Manrope and Space Grotesk fonts, and a dynamically imported Three.js hero scene. See the project [README](../README.md) for installation requirements, compatibility limits, usage, and current release status. Third-party sources and licenses are listed in [ATTRIBUTIONS](../ATTRIBUTIONS.md).
